# אפליקציה לעדכון מגרשים

זו גרסת הדגמה למנהל אחד, באזור תעשייה אחד. כל העדכונים נשמרים רק בדפדפן של המחשב הזה, לא בשרת ולא בתוך שכבות המפה.

המפה מציגה את גבול האזור ואת המגרשים שבתוכו. לחיצה על מגרש פותחת טופס. המצב הישן מהסקר נשאר לקריאה. מה שהמנהל ממלא נשמר בנפרד.

## איך מפעילים

1. התקינו Node.js מהאתר https://nodejs.org (הגרסה המומלצת, LTS). זו תוכנה שמריצה את האפליקציה על המחשב.
2. פתחו את תיקיית הפרויקט.
3. פתחו חלון פקודות בתוך התיקייה.
4. הקלידו את הפקודה הבאה ולחצו Enter. זה מוריד את החלקים שהאפליקציה צריכה. עושים את זה פעם אחת:

```
npm install
```

5. הקלידו:

```
npm run dev
```

6. השאירו את החלון פתוח. בדפדפן כרום פתחו את הכתובת שמופיעה, בדרך כלל:

```
http://localhost:5173
```

7. כדי לעצור, חזרו לחלון הפקודות ולחצו Ctrl+C.

## איך מכינים אפליקציה לאזור אחר

אין צורך לשנות קוד. רק שם אחד.

1. פתחו את הקובץ `src/config.ts` בעורך טקסט.
2. שנו את השם שבתוך המרכאות בשורה `zone`.
3. השם חייב להיות זהה לאחד השמות האלה (כולל הגרשיים ב«צח"ר»):

- בוקעאתא
- בני יהודה
- דלתון
- חצור הגלילית
- מג'דל שמס
- מסעדה
- צח"ר
- צפת
- קצרין
- קרית שמונה דרום
- קרית שמונה צפון

ברירת המחדל היא **קצרין**.

בשכבת המגרשים האזור צח"ר כתוב בלי גרשיים («צחר»). האפליקציה מזהה שזה אותו אזור. בשאר השמות הכתיב זהה.

4. שמרו את הקובץ ורעננו את הדפדפן.

אפשר גם לשנות שני שמות נוספים באותו קובץ:

- `clusterName` — השם שמופיע מעל שם האזור בכותרת.
- `managerName` — השם שנרשם אוטומטית כמי שעדכן.

## מה רואים במסך

- למעלה: שם האזור, וההנחיה ללחוץ על מגרש במפה.
- מספרים: כמה מגרשים יש, כמה פנויים, כמה בנויים, כמה בנויים חלקית. מתחת לכל מספר מופיע גם השטח בדונם.
- גרף מצב בנייה, גרף לפי ייעוד הקרקע, ופס «עודכנו X מתוך Y מגרשים».
- מפה של האזור בלבד. אי אפשר לגלול רחוק מחוץ לאזור. צבע המגרש הוא לפי העדכון של המנהל. אפור אומר שעדיין אין עדכון. קו כתום מקווקו אומר שהעדכון ישן (יותר מחצי שנה).
- לחיצה על מגרש פותחת טופס. שומרים, והמספרים מתעדכנים מיד.

«מצב בנייה לפי הסקר» בטופס הוא הנתון הישן מהשכבה. הוא לא משתנה כששומרים. המצב שנשמר הוא מה שהמנהל בחר.

אם יש עסק מהסקר שנקודתו נופלת בתוך המגרש, שמו מופיע בטופס. עסק שהנקודה שלו מחוץ למגרש לא משויך אליו.

## נתוני הדגמה

בפעם הראשונה שנפתח האזור קצרין, ארבעה מגרשים מקבלים דוגמה: מגרש 300, מגרש 715, מגרש 37 ומגרש 13. הם מסומנים במסך במילה «הדגמה». אלה לא נתוני אמת.

אחרי שמירה, הרשומה הופכת לעדכון רגיל.

כדי לחזור לדוגמה: בדפדפן, נקו את נתוני האתר עבור `localhost` (Site settings → Clear data) ורעננו.

## מפת המקור

שלושה קבצי מקור:

- `Industry_Area_ (1).zip` — גבולות 11 אזורי התעשייה.
- `Industrial_areas_cat.zip` — 739 מגרשים.
- `IndustryPoint_Eskhol (2).zip` — נקודות העסקים מהסקר.

שתי שכבות הפוליגון הגיעו ברשת ווב מרקטור (EPSG:3857), לפי קובץ ההגדרה שלהן. קובץ ה־XML של המגרשים עדיין מזכיר רשת ישראל; זה תיאור ישן, וההמרה לא השתמשה בו. נקודות העסקים הגיעו ברשת ישראל (EPSG:2039).

האפליקציה משתמשת בקבצים `src/data/zones.json`, `src/data/parcels.json` ו־`src/data/businesses.json`. כולם באורך ורוחב (EPSG:4326). לא הושמטה אף נקודת צורה, ולא הוזזה אף צורה. רק שיטת הקואורדינטות הוחלפה.

בעמודת `Dunam` בשכבת המגרשים המספרים הם מטרים רבועים, לא דונם. זה תואם את שטח הפוליגון. במסך השטח מוצג בדונם אחרי חלוקה ב־1,000.

אם מחליפים את קובצי המקור, אפשר ליצור את הקבצים מחדש:

```
pip install pyshp pyproj
python3 scripts/convert_shp_to_geojson.py
```
