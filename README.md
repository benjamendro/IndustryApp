# אפליקציה לעדכון עסקים

זו גרסת הדגמה למנהל אחד, ברשות אחת. כל העדכונים נשמרים רק בדפדפן של המחשב הזה, לא בשרת.

המפה מציגה עסקים (נקודות) מתוך הסקר. אין כאן עדיין גבולות של מגרשים. כשיועלו פוליגונים של מגרשים, אפשר יהיה להחליף את הנקודות.

## איך מפעילים

1. התקינו Node.js מהאתר https://nodejs.org (הגרסה המומלצת, LTS). זו תוכנה שמריצה את האפליקציה על המחשב.
2. פתחו את תיקיית הפרויקט.
3. פתחו חלון פקודות בתוך התיקייה.
4. הקלידו את הפקודה הבאה ולחצו Enter. זה מוריד את החלקים שהאפליקציה צריכה. עושים את זה פעם אחת:

```
npm install
```

5. הקלידו:

```
npm run dev
```

6. השאירו את החלון פתוח. בדפדפן כרום פתחו את הכתובת שמופיעה, בדרך כלל:

```
http://localhost:5173
```

7. כדי לעצור, חזרו לחלון הפקודות ולחצו Ctrl+C.

## איך מכינים אפליקציה לרשות אחרת

אין צורך לשנות קוד. רק שם אחד.

1. פתחו את הקובץ `src/config.ts` בעורך טקסט.
2. שנו את השם שבתוך המרכאות בשורה `authority`.
3. השם חייב להיות זהה לאחד השמות האלה:

- בוקעאתא
- ג'ש (גוש חלב)
- גולן
- הגליל העליון
- חצור הגלילית
- מבואות החרמון
- מטולה
- מרום הגליל
- צפת
- קצרין
- קרית שמונה
- ראש פינה

ברירת המחדל היא **קצרין**.

4. שמרו את הקובץ ורעננו את הדפדפן.

אפשר גם לשנות שני שמות נוספים באותו קובץ:

- `clusterName` — השם שמופיע מעל שם הרשות בכותרת.
- `managerName` — השם שנרשם אוטומטית כמי שעדכן.

## מה רואים במסך

- למעלה: שם הרשות, וההנחיה ללחוץ על עסק במפה.
- מספרים: כמה עסקים יש, כמה פנויים, כמה בנויים, כמה בנויים חלקית.
- שני גרפים, ופס התקדמות «עודכנו X מתוך Y עסקים».
- מפה עם העסקים של הרשות בלבד. צבע לפי מצב הבנייה. קו מקווקו אומר שהעדכון ישן (יותר מחצי שנה) או שעדיין אין עדכון.
- לחיצה על עסק פותחת טופס. שומרים, והמספרים מתעדכנים מיד.

אם כמה עסקים יושבים על אותה נקודה, מופיע מספר על הנקודה. בטופס בוחרים איזה עסק לעדכן.

## נתוני הדגמה

בפעם הראשונה שנפתחת הרשות קצרין, ארבעה עסקים מקבלים דוגמה (יקב הגולן, מי עדן, מאפיית קצרין, נורדסון מדיקל). הם מסומנים במסך במילה «הדגמה». אלה לא נתוני אמת.

אחרי שמירה, הרשומה הופכת לעדכון רגיל.

כדי לחזור לדוגמה: בדפדפן, נקו את נתוני האתר עבור `localhost` (Site settings → Clear data) ורעננו.

## מפת המקור

הקובץ `IndustryPoint_Eskhol (2).zip` הוא שכבת הנקודות המקורית, ברשת ישראל (EPSG:2039). האפליקציה משתמשת בקובץ `src/data/businesses.json`, בפורמט GeoJSON, שכבר הומר לאורך ורוחב (EPSG:4326). לא שונתה צורה של אף נקודה, רק שיטת הקואורדינטות.

אם מחליפים את קובץ המקור, אפשר ליצור את הקובץ מחדש:

```
pip install pyshp pyproj
python3 scripts/convert_shp_to_geojson.py
```
